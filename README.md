功能概述
项目包含 OCR 相关处理，具体功能待补充。
目录结构
AndroidManifest.xml：Android 应用清单文件，配置应用基本信息、权限、组件等。
MainActivity：主活动类（推测），处理应用界面和交互。
MyApplication.kt：可能是应用入口类，继承 Application，用于全局配置。
OCRBackgroundService.kt：OCR 后台服务类，处理 OCR 相关后台任务。
OCRProcessor.kt：OCR 处理类，实现 OCR 核心逻辑。
build.gradle.kts：构建脚本，配置项目依赖、构建参数等。
settings.gradle.kts：项目设置脚本，包含项目模块配置。
